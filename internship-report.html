INTRODUCTION

Cloud computing is a model for delivering computing resources such as virtual servers, object storage, networking, security controls, and application services over the Internet on an on-demand, pay-as-you-go basis. Amazon Web Services (AWS) provides a comprehensive, highly secure, and globally distributed suite of cloud services that can be combined to architect, deploy, and maintain modern web applications with enterprise durability and zero on-premise hardware overhead.

This internship training project applies practical AWS cloud concepts to a full-stack, production-ready web application named L'Aura Bistro — Digital Restaurant Menu Website. The application functions as an interactive, luxury digital dining catalog allowing patrons to browse categorized gourmet food selections, conduct live dish searches, review dietary certifications (Vegetarian, Vegan, Gluten-Free), and stream high-definition culinary media clips.

The application architecture eliminates traditional database overhead by utilizing a structured, lightweight JSON data repository. The server logic is hosted on an Amazon Elastic Compute Cloud (EC2) virtual instance running Ubuntu Linux, managed continuously through PM2 and reverse-proxied via Nginx on public HTTP Port 80.

All high-resolution culinary photography and promotional kitchen video assets are stored securely in a private Amazon Simple Storage Service (S3) bucket with Block Public Access fully enabled. Media files are dynamically streamed to visitors using temporary cryptographic Presigned URLs generated by the backend Express server.

The project demonstrates an end-to-end cloud workflow involving single-page React architecture, REST API communication, automated Linux process daemonization, AWS IAM Instance Role authorization (completely eliminating hardcoded credentials), and continuous GitHub-based cloud deployment.

FAMILIARIZATION WITH CLOUD COMPUTING AND AWS

The training begins with the fundamental cloud concepts required to understand the project architecture:

  1. Cloud Computing: On-demand access to virtualized computing resources, storage, and networking over the Internet.
  2. Amazon EC2: Resizable virtual compute capacity used in this project to host the Node.js Express server and compiled React application.
  3. Amazon S3: Secure, high-durability object storage used to store private culinary photos and promotional restaurant videos.
  4. AWS IAM: Identity and Access Management used to securely govern permissions between the EC2 compute instance and the S3 bucket.
  5. IAM Role / Instance Profile: Allows the EC2 application to obtain temporary, automatically rotated AWS credentials without storing permanent access keys on the server.
  6. Security Group: Acts as a virtual firewall controlling inbound network traffic to the EC2 instance (allowing Port 80 HTTP and restricting Port 22 SSH).
  7. PM2 & Nginx: PM2 maintains continuous backend uptime with auto-restart upon server reboot, while Nginx handles public Port 80 reverse-proxy routing.

The documented production deployment uses Ubuntu Server 24.04 LTS on EC2, Amazon S3 in the Sydney region (ap-southeast-2), Node.js 20, Express.js, React.js, Tailwind CSS, AWS SDK for JavaScript v3, PM2, and Nginx.

PROJECT OVERVIEW AND OBJECTIVES

Project Name: L'Aura Bistro — Digital Restaurant Menu Website

L'Aura Bistro is a modern, high-performance, single-page restaurant catalog application. It addresses the operational and financial challenges of traditional printed dining menus by providing an interactive digital showcase with live dish filtering, full-text ingredient searching, dietary classifications, kitchen promotional video streaming, and an administrative S3 cloud manager.

Primary Objectives

  • Develop a responsive, mobile-first single-page web application using React.js, Vite, and Tailwind CSS.
  • Eliminate database management complexities (MongoDB/MySQL) by utilizing a structured, reliable JSON data source (data/menu.json).
  • Store high-resolution dish photography and promotional video clips in private Amazon S3 object storage with Block Public Access enabled.
  • Implement secure, zero-credential authentication using an AWS EC2 IAM Instance Role, strictly avoiding hardcoded AWS Access Key IDs or Secret Access Keys.
  • Generate temporary S3 Presigned GET URLs on the Express backend with a 1-hour expiration time to securely stream private media to authenticated clients.
  • Provide a secure, PIN-protected Admin Manager allowing authorized staff to import starter menu media and upload new dish photos directly into Amazon S3.
  • Host the full-stack system on an AWS EC2 Ubuntu instance using PM2 for process uptime and Nginx as a reverse proxy on Port 80.
  • Establish an automated, repeatable GitHub-based continuous deployment workflow (git push locally → git pull & pm2 restart on EC2).

SYSTEM ARCHITECTURE

The application follows a resilient Three-Tier Cloud Architecture:

1. Client Tier: Runs in the diner's web browser. Built with React.js and styled with Tailwind CSS, it executes search filtering, category selection, and video streaming without full page reloads.

2. Application Tier: Runs on an AWS EC2 Ubuntu instance. Express.js handles REST API endpoints, static React hosting, Multer file upload streaming, and S3 Presigned URL signing. Nginx manages Port 80 ingress and Gzip compression, while PM2 ensures process resilience.

3. Storage Tier: Amazon S3 stores private food photographs and promotional video files. Content remains non-public and is delivered exclusively through time-limited cryptographic presigned URLs.

AWS DEPLOYMENT PROCESS

  1. Step 1: Create private S3 bucket expense-splitter-app-2026 in ap-southeast-2 with Block Public Access enabled.
  2. Step 2: Create IAM Role EC2-Restaurant-S3-Role with S3 GetObject, PutObject, and ListBucket permissions.
  3. Step 3: Launch an Ubuntu Server 24.04 LTS EC2 instance (t3.micro) and attach the IAM Role.
  4. Step 4: Configure Security Group: Allow HTTP Port 80 from 0.0.0.0/0 and SSH Port 22 from personal IP.
  5. Step 5: Connect to EC2 via SSH: ssh -i restaurant-key.pem ubuntu@3.26.210.235.
  6. Step 6: Install Node.js 20 LTS, Git, PM2, and Nginx.
  7. Step 7: Clone the GitHub repository: git clone https://github.com/Prishu07/digital-restaurant-menu.git.

SECURITY, COST, LIMITATIONS AND FUTURE IMPROVEMENTS

Security Considerations

  • S3 Block Public Access: Fully enabled; direct unauthenticated public access to bucket objects is blocked.
  • IAM Least Privilege: EC2 uses an IAM Instance Profile; no AWS access keys are stored in code or on disk.
  • Reverse Proxy Shield: Internal Port 3000 is closed to the internet; Nginx inspects all traffic on Port 80.
  • Upload Guard: Nginx enforces client_max_body_size 50M; to handle photos while blocking buffer floods.

Cost Considerations

  • Built on AWS Free Tier eligible resources: t3.micro EC2 instance and standard S3 storage.
  • In-memory backend caching of presigned URLs (45-min TTL) prevents redundant signing calculations.

Current Scope and Limitations

  • Included: Single-page UI, live search, category filter, S3 presigned media streaming, PIN-protected admin manager, EC2 Ubuntu hosting with Nginx and PM2.
  • Not Included: Multi-tenant customer logins, online table ordering/payment checkout, and automated SSL domain binding.

Possible Future Improvements

  • Automated SSL/TLS certificate installation via Let's Encrypt Certbot (https://).
  • Amazon CloudFront CDN integration for edge caching of high-resolution food photography.
  • Online customer table reservation system and digital payment gateway integration.
